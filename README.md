# Home Price Predictor

## Overview
Home Price Predictor is a machine learning web app that predicts estimated home prices based on property features.

This project demonstrates an end-to-end regression machine learning workflow, including data preparation, model training, prediction logic, and deployment.

## Live Demo
https://home-predictor.onrender.com/

## What This Project Shows
- Regression machine learning
- Python development
- Flask web app structure
- Model training and prediction
- End-to-end deployment
- User-facing ML application design

## Tech Stack
- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML/CSS
- Render
- GitHub

## Business Use Case
This project demonstrates how machine learning can support real estate valuation and pricing estimation workflows.
